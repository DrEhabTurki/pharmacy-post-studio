# استوديو بوستات صيدليات د/ مراد صادق

## النشر من موبايل Android مجاناً عبر GitHub Pages
1. افتح github.com من Chrome وسجّل الدخول.
2. اضغط علامة + ثم New repository.
3. الاسم: `pharmacy-post-studio`، واختر Public ثم Create repository.
4. افتح المستودع > Add file > Upload files.
5. فك ضغط ZIP على هاتفك (من تطبيق الملفات)، ثم ارفع الملفات الخمسة الموجودة داخل مجلد المشروع، وليس ملف ZIP نفسه.
6. اضغط Commit changes.
7. افتح Settings > Pages.
8. تحت Build and deployment اختر Deploy from a branch، ثم `main` و`/(root)` ثم Save.
9. بعد اكتمال النشر افتح رابط Pages. في Chrome اضغط ⋮ ثم Add to Home screen أو Install app.

## الاستخدام
- ارفع صورة اللوجو الأصلي أول مرة؛ يحفظ محلياً في المتصفح.
- اختر نوع البوست واكتب العنوان والمحتوى وارفع صورة المنتج.
- اضغط تنزيل PNG. المقاس 1080×1920 مناسب لحالة واتساب.
- احفظ التصميمات لإعادة استخدامها على نفس الجهاز.

## تنبيهات
- التخزين محلي على نفس المتصفح والجهاز؛ مسح بيانات الموقع قد يحذف اللوجو والتصميمات المحفوظة.
- هذا إصدار أولي: تحريك العناصر بالسحب وتحرير كل طبقة بشكل مستقل غير متاحين بعد.
- راجع صحة المعلومات الطبية والادعاءات التسويقية قبل النشر.
- لا توجد مفاتيح API أو خدمات مدفوعة ضمن التطبيق؛ حدود GitHub أو تغيّر سياساته تظل خارج سيطرة التطبيق.
