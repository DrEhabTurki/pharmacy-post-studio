# استوديو بوستات صيدليات د/ مراد صادق

نسخة القالب الأسود والبرتقالي الفاخر، بمقاس 1080×1920.

ارفع الملفات الستة إلى جذر مستودع GitHub، ثم فعّل GitHub Pages من Settings → Pages → Deploy from a branch → main → /(root).

ارفع اللوجو الأصلي وصورة المنتج، ثم عدّل العنوان والوصف والمكونات والنقاط السفلية واضغط تنزيل PNG. التطبيق يعمل محليًا دون API أو اشتراك. راجع دقة المعلومات الصحية والادعاءات التسويقية قبل النشر.
